## How to use this section

- An item that is picked up moves to 🟡 and, if it has substance, earns its own doc in this folder
  (`backlog/<slug>.mdx`), linked from the **Detail** column.
- When an item is finished: move the learning into the matching feature or architecture doc and drop
  it from the map (or mark it ✅ and archive it).
- Keep **Status** and **Effort** current — this map is the source of truth for "what's next".

### Template for an item with its own doc

```markdown
---
title: <Item title>
description: <one line>
---

# <Item title>

<what hurts, or what is gained>

## Proposal
<approach, alternatives, decision>

## Notes to pick it back up
<links, affected files, what was learned — enough not to re-research it>
```
