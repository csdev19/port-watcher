## Open and close the panel

- **Click the menu-bar icon** to open the panel under it. Click again to close it.
- **Press `⌥⌘P`** from anywhere to toggle it.
- The panel closes by itself when you click outside it, and with `Esc`.

The list refreshes every two seconds while the panel is open.

## Read the list

**Listening** shows one row per listening port: the port, a plain label for what the process is,
the project folder it runs from, and its uptime. Press `Enter` or click a row to expand it and see
more detail, including the full command.

Rows are grouped:

- **Dev**: processes you started yourself, such as dev servers and databases. Listed first.
- **Apps & System**: processes inside an `.app` bundle, system services, and anything owned by
  another user. This section starts collapsed each time the panel opens. App rows can be killed;
  system and other-user rows are listed for information only.

## Search

Type to filter by port, app or folder. Search covers every row, including the collapsed
**Apps & System** section.

## Kill a process

Killing takes two steps, so a stray click cannot end the wrong thing.

1. Click the **×** on the row. It changes to a confirmation: **Kill?** for a dev row, **Kill app?**
   for an app row.
2. Click it again **within two seconds**. If you do not, it disarms.

chapay asks the process to stop first and forces it only if it has not exited after about two
seconds. A toast reports a failure. A row with a lock icon cannot be killed: it belongs to another
user or is a macOS system service. The Rust core refuses those kills even if the panel asked for
one (see [Permissions](/desktop/permissions)).

### Keyboard

| Key                      | Action                                     |
| ------------------------ | ------------------------------------------ |
| `↑` / `↓`                | Move the selection                         |
| `Enter`                  | Expand or collapse the selected row        |
| `⌘⌫`                     | Kill the selected row (see the note below) |
| `Esc`                    | Close the panel                            |
| `←` / `→` on the tab bar | Switch between Listening and Favourites    |

:::note[`⌘⌫` kills a dev row immediately]
For a **dev** row the keyboard shortcut skips the two-step confirmation. For **app** rows, press
`⌘⌫` twice within two seconds. While the cursor is in the search box, `⌘⌫` only clears your text
(the usual macOS "delete to line start") and never kills the selected row. Holding the keys down
does not repeat the kill.
:::

:::caution[Differences in the released `0.1.0` build]
`0.1.0` was released before three fixes that are now on `main` and ship with the next desktop
release:

- A left click on the menu-bar icon showed the Quit menu instead of the panel (the panel opened with
  `⌥⌘P`); the menu now appears on right click only.
- `⌘⌫` in the search box could kill the selected dev process. Until you update, clear the box with
  `⌘A` then `⌫`.
- System services could be killed from the panel (**Kill system?**); the core now refuses them.
  :::

## Machine tab

The panel has two tabs, **Ports** and **Machine** (`⌘1` and `⌘2`). The panel always opens on
Ports.

Machine shows four gauges: CPU, GPU, Heat and Memory. Each one has the current value, what is
driving it, the reference band in words, and the last 60 seconds as a small chart with the warn
and stop lines. The pill in the header shows the overall verdict (OK, Watch or Stop).

- **Heat** shows the CPU hotspot in degrees next to macOS's thermal pressure word. The hotspot
  can pass 95 °C while macOS still says "Nominal", so the gauge turns red on the temperature
  alone.
- **Memory** is coloured by macOS memory pressure, not by how much is used, because macOS keeps
  most memory in use on purpose.
- **Top by CPU** lists the busiest apps. Helpers of one app are grouped (for example "Cursor ·
  4 processes"), and the percentage is a share of the whole machine.

The ✕ on a row stops **one** process: the app's main process when it is running, otherwise the
busiest one. It always takes two steps (click or `⌘⌫`, then confirm within two seconds), and
system processes, other users' processes and chapay itself show a lock instead.

The Machine tab reads the machine once a second, only while it is the active tab and the panel is
open. With the panel closed chapay does not sample anything.

## Favourites

Favourites are ports you want to keep an eye on, even when nothing is running on them.

- Click the **star** on a row to watch that port, or open the **Favourites** tab and add a port
  number (with an optional name) using the watch form.
- The tab lists each watched port with whatever is listening on it right now, or **nothing
  listening** when the port is free. You can kill from there with the same two-step flow, rename a
  favourite, or remove it.
- A favourite remembers the port number, not the process, so it survives restarts of the process
  and of chapay. It is stored on your Mac only.
- Opening the panel always starts on the Listening tab.

## Updates

chapay checks for a newer version once when it opens and then once a day. The check asks one file
on chapay's download server which version is newest; it sends no app version, identifier or
setting. To turn it off, open Settings › General and switch off **Check for updates
automatically**. You can always check by hand in Settings › About › **Check for updates**.

When a newer version exists:

- A slim bar appears at the top of the panel: "chapay 0.3.0 is available". The gear in the panel's
  footer gets a small pink dot.
- **Update** downloads and installs it (about 2 MB, a few seconds). The bar shows the progress,
  then **Restart to update**. Nothing installs, and chapay never restarts, until you click.
- **×** hides the bar for that version. The dot stays, and Settings › About still offers the
  update. A newer version brings the bar back.
- Settings › About runs the same steps: **Update to 0.3.0**, then **Restart chapay**.

Before installing, chapay checks that the download is signed by chapay's developer (both the
update signature and Apple's Developer ID signature). If a check fails, nothing is installed and
About offers **Download instead**, which opens the release page.

## Quit

Right-click the menu-bar icon and choose **Quit**. Closing the panel does not quit the app.
