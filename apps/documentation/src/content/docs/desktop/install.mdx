---
title: Install chapay
description: Download the right build, drag it to Applications, and get past the first-launch prompt
---

chapay is a macOS menu-bar app. It is free and open source, and the installer is a signed and
notarized `.dmg`.

## 1. Download the right build

There are two builds, one per kind of Mac. Pick the one that matches your chip:

| Your Mac                      | File               | How to check                                           |
| ----------------------------- | ------------------ | ------------------------------------------------------ |
| Apple silicon (M1, M2, M3, …) | `chapay-arm64.dmg` | Apple menu → About This Mac shows **Chip: Apple M…**   |
| Intel                         | `chapay-x64.dmg`   | Apple menu → About This Mac shows **Processor: Intel** |

[chapay.cs19.dev](https://chapay.cs19.dev) has two buttons side by side, **Download for Apple
silicon** and **Download for Intel**. The page does not guess your chip, because Apple silicon Macs
report themselves as Intel to a browser. If the page does not know the download location, both
buttons fall back to the [GitHub Releases](https://github.com/csdev19/port-watcher/releases) page,
where the files are named `chapay-<version>-arm64.dmg` and `chapay-<version>-x64.dmg`.

If you install the wrong build, it either refuses to open (an Apple silicon build on an Intel Mac)
or runs through Rosetta (an Intel build on Apple silicon). Delete it and install the other one.

chapay needs **macOS 13 (Ventura) or later**. The bundle sets `minimumSystemVersion` to `13.0`, so
macOS refuses to open it on an older system. That setting was added after `0.1.0`, so it applies from
the next desktop release; the landing page already states macOS 13+.

### Verify the download (optional)

Each release also publishes a `SHA256SUMS` file next to the DMGs, both in the download folder and on
the GitHub Release. Each copy lists the file names used in its own place (`chapay-arm64.dmg` for
the download folder, `chapay-<version>-arm64.dmg` on GitHub), so use the copy that matches your
file. Put it in the same folder as the DMG and run
`shasum -a 256 -c SHA256SUMS --ignore-missing`.

## 2. Install it

1. Open the downloaded `.dmg`.
2. Drag **chapay** onto the **Applications** folder in the window that opens.
3. Eject the disk image and open **chapay** from Applications (or Spotlight).

## 3. The first-launch prompt

The build is signed with a Developer ID certificate and notarized by Apple, so macOS lets it run
without any workaround. Because the file came from the Internet, the first launch still shows the
standard macOS dialog saying that chapay is an app downloaded from the Internet and asking whether
you want to open it. Choose **Open**. You only see it once.

If macOS instead says it cannot verify the app, or that it is damaged, do not bypass it: you
probably have a partial download or a copy that did not come from the official release. Download it
again from the links above.

## 4. Find it

chapay has **no window and no Dock icon**. After it starts, look for its icon in the menu bar, near
the clock. Click it, or press `⌥⌘P`, to open the panel. See [Using chapay](/desktop/usage).

To quit, right-click the menu-bar icon and choose **Quit**.

## Updating

From version 0.2.0, chapay updates itself after you click **Update** (see
[Updates](/desktop/usage#updates)). Version 0.1.0 has no updater: install 0.2.0 by hand once —
quit chapay, download the newest DMG and drag the new app over the old one in Applications.

Keep chapay in Applications. A copy run straight from the DMG or from Downloads cannot replace
itself, and chapay says so ("Move chapay to Applications to update").
